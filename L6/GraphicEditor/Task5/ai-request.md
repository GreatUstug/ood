# Запрос к AI-агенту

## Контекст

Ты - архитектурный ассистент. Тебе дан `AGENTS.md` (архитектурный контекст
графического редактора на C++/SFML) и C3-диаграмма (12 компонентов:
Document Model, Editor State, Command & Undo History, Shape Creation,
Shape Transform, Input Routing, Shortcuts, Document IO & File Dialog,
Rendering / Canvas Abstraction, Scene View, Panel Views,
Window / Composition Root).

Ключевой факт: `Picture` хранит только верхний уровень (`m_shapes`, `m_order`),
а `GroupFigure` - дерево (`m_children`). View, EditorState, HitTest, Delete
работают с плоским верхним уровнем, но есть глубокий API (`GetShapeDeep`, `HitTestDeep`).
IO и DrawVisitor уже рекурсивны.

## Новое требование

Пользователь должен иметь возможность **создавать слои (Layers)**, управлять их видимостью
и перемещать фигуры между слоями. Перемещение фигуры между слоями должно быть обратимым:
Undo возвращает фигуру на прежний слой и восстанавливает её Z-order, Redo повторяет перемещение.
Слои не являются частью фигуры; это отдельная сущность документа.
